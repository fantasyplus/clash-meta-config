## Files

- `config.yaml`: main Clash/Mihomo config for Clash Meta for Android.

## Replace before use

In `config.yaml`, replace this value:

```yaml
url: "REPLACE_WITH_YOUR_AIRPORT_SUBSCRIPTION_URL"
```

with your Clash/Mihomo-format airport subscription URL.

## Raw subscription link format

After `config.yaml` is committed to your GitHub repository, the Clash Meta for Android subscription URL is:

```text
https://raw.githubusercontent.com/<owner>/<repo>/<branch>/config.yaml
```

For this repository:

```text
https://raw.githubusercontent.com/fantasyplus/clash-meta-config/main/config.yaml
```

Use this raw URL in Clash Meta for Android as a URL/subscription profile.

## Important

Do not commit an airport subscription URL with `token`, `uid`, or `sid` into a public repository.
